# 🔔 לא לשכוח

אפליקציה למשפחה, בטלפון ובמחשב, כדי לא לשכוח דברים: קניות, משימות ותוכניות, עם תאריכים ותזכורות. כל המשפחה רואה את אותן משימות.

## איפה
- **אתר (גם למחשב):** https://484963-ctrl.github.io/lo-lishkoach/
  בכרום או באדג׳ אפשר ללחוץ על „התקנה” בשורת הכתובת, והאתר נפתח בחלון משלו כמו תוכנה.
- **דף מידע והורדות (לשלוח למשפחה):** https://484963-ctrl.github.io/lo-lishkoach/info/
- **אפליקציה לטלפון (אנדרואיד):** https://github.com/484963-ctrl/lo-lishkoach/releases/latest/download/lo-lishkoach.apk
  גרסה חדשה מותקנת מעל הקודמת והנתונים נשמרים (חתימה קבועה, `debug.keystore`).

## מה יש בה
- **נושאים:** 📦 קניות מאליאקספרס, 🛒 קניות בסופר, ✅ משימות, 🏗️ תוכניות לבנייה. אפשר לשנות שם, למחוק ולהוסיף (⚙️ או „+ נושא”). לחיצה על הסמל של נושא מחליפה אותו באימוג׳י אחר או בתמונה מהגלריה, מהמצלמה או מהמחשב (גרירה או הדבקה).
- **הוספה מהירה:** „לשלם חשמל מחר 18:00”, „להתקשר לקבלן ביום שני”, „ארנונה 15.11”. התאריך והשעה נקלטים לבד, ומהמסך „הכול” המשימה נכנסת לנושא המתאים לפי מילים.
- **לכל משימה:** תאריך, שעה, תזכורת (בזמן, רבע שעה, שעה, יום או שבוע לפני), חזרה (כל יום/שבוע/חודש/שנה), מי אחראי, קישור והערות.
- **לפי זמן:** באיחור (באדום), היום, מחר, השבוע, בהמשך, בלי תאריך. משימה חוזרת שמסמנים כבוצעה עוברת לפעם הבאה.
- **תזכורות:** בטלפון, התראות שמגיעות גם כשהאפליקציה סגורה (`@capacitor/local-notifications`). באתר ובמחשב: התראה כשהדף פתוח, וכפתור „ליומן Google”.
  מי שכותב את שמו ב־⚙️ לא מקבל תזכורות של משימות ששויכו למישהו אחר.
- **שיתוף עם המשפחה:** 👨‍👩‍👧 ← „יצירת קוד משפחתי” ← „שליחת הזמנה”. עובדת גם בלי אינטרנט, והשינויים נשלחים כשהחיבור חוזר.

## מבנה
- `www/` – האפליקציה עצמה (קובץ HTML אחד), גם לאתר וגם לטלפון.
- `www/config.js` – כתובת Supabase והמפתח הציבורי.
- `supabase/schema.sql` – טבלה `lo_lishkoach_families` ושתי פונקציות (`lo_lishkoach_get`, `lo_lishkoach_put`). כבר הופעל.
- `android-res/` – אייקון, מסך פתיחה וסמל להתראות.
- `scripts/build-apk.sh` – בניית ה־APK (`npm ci && npm run android:apk`, צריך Java 21 ו־Android SDK).
- `.github/workflows/build-apk.yml` – בונה APK בכל עדכון של `main` ומפרסם בקישור הקבוע.
- `.github/workflows/pages.yml` – מעדכן את האתר. פעם אחת צריך להפעיל: Settings ← Pages ← Source: GitHub Actions.
